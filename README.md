# Mia English Lab 網站

靜態網站已從 GitHub Pages 的 `main` 分支根目錄發布：<https://nekonano-q.github.io/profolio_mia/>。網站檔案是 `index.html`、`styles.css` 與 `assets/`，沒有建置步驟或套件依賴。

## 更新網站

修改這個資料夾中的網站檔案後，在 Finder 雙擊 `更新網站.command`。程式會提交並推送網站檔案；`github_io.txt` 與更新程式本身不會上傳。若 GitHub 上有其他人新增的變更，程式會停止，避免覆蓋。

這台 Mac 的 Git 需先完成一次 `nekonano-q` 帳號驗證。瀏覽器與 Codex GitHub 連線的登入不會自動提供給本機 Git。程式不會儲存密碼或 token；若推送時提示驗證，請使用自己的 GitHub 憑證完成。驗證儲存在 macOS 鑰匙圈後，之後可直接雙擊更新。

## 公開展示內容

網站使用從專案照片挑選並壓縮的 WebP 圖片。證照僅放公開展示版本：碩士證書的生日與證書編號已遮蔽，原始證照留在上層專案的 `證照/`，未上傳至網站。原始照片與證照未被修改。

聯絡信箱目前留白。公開網站前，請確認學生照片、作品與過去任職機構畫面可以展示，以及「新竹地區 1–5 人小班」符合目前的課程安排。
